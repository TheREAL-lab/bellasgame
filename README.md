# bellasgame

A 3D hide-and-seek game built in Godot 4, made together with my step-daughter Bella.

## The idea

- 5 players total: Bella, me, and 3 AI-controlled players.
- Multiplayer, so Bella and I can play together over the network.
- Each round, one random player is picked as the Hunter — everyone else hides.
- Cute, squishy props and characters throughout, because that's what makes it fun for a 7-year-old.

## Status

Just getting started — this repo currently has the project scaffold only.
